# Janan 26.11.0+84

- Upgrade to Flutter 3.50, Dart 3.14, and the standalone Material UI packages.
- Use published Safaeh 1.1.0 and settings framework 1.0.0; remove temporary UI
  compatibility copies and the inline_tab_view dependency.
- Preserve unsaved values across input tabs, animate form height, and respect
  reduced motion and keyboard accessibility.
- Add offline-capable web builds with Wasm and JavaScript fallback.
- Refresh Body profile/settings layouts, desktop navigation, and localized copy.
- Improve connected-scale reading review and prevent deleted readings from
  returning during reconnection.
- Include offline health tools, selected-diary backups, supply forecasts, and
  dated target charts. Free offline usage remains unlimited.

Android assets include the production package (`janan-…`) for existing
installations and the separate FOSS package (`janan-foss-…`). Hosted features remain
subscription-gated and disabled by the existing launch controls. Payment-provider
activation is not part of this release.

## Validation

Release checks: code generation, all 25 translation files, clean analysis,
3,253 tests (nine opt-in skips), 17 daylight-saving checks, all seven goldens
with unchanged baselines, Android debug build, native widget tests, offline
worker/packaging tests, and signing-property round trip. All four locally built
release APKs use the same non-debug signing certificate as 26.10.10; the symbols
archive includes Dart symbols and the R8 mapping. No attached device was
available for a physical-device smoke test. The release tag is pushed only
after CI passes on the exact versioned commit.
